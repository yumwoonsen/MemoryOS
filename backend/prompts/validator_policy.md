# Deterministic validation policy

Validation remains code-driven even when earlier stages use a language model. It checks:

1. Every cited event exists in the input Memory Pack and keeps its original event type.
2. Every opted-in member receives exactly one distinct perspective with canonical identity fields.
3. Perspective and objective evidence belongs to the discovered memory, not merely the same match.
4. No unsupported relationship labels or unsafe quest instructions are introduced.
5. Quests require one mandatory squad reunion plus grounded, unique, supported objectives.
6. Human confirmation state is preserved exactly.
7. Weak, eventless, or consent-insufficient inputs abstain instead of manufacturing nostalgia.

User-visible factual prose is rendered deterministically from the selected structure before these
checks run; model-written prose is not treated as proof of grounding.
